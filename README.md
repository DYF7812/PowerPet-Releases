# PowerPet

**面向 Windows 的 AI 文件管理助手，让文件查找、内容处理与日常整理集中在一个工作界面中。**

PowerPet 将 AI 对话、文件管理、临时文件中转和截图工具结合起来，服务于学习、办公和个人资料整理。你既可以通过图形界面处理文件，也可以用自然语言提出需求，由 AI 理解任务并调用工具辅助完成。

**管理范围覆盖用户授权的本机文件和文件夹，包括文档、下载、项目目录及其他磁盘中的资料，不限于桌面文件夹。**

## 核心功能

### 1. AI 对话与工具调用

启动后默认打开助手主窗口，右侧为文件中心，可以一边查看文件，一边与助手对话。

- 使用自己的 API Key / Token，选择模型和思考等级，支持多任务会话、历史记录和流式回答。
- 通过 `@` 或拖放引用中转站文件，通过 `/` 选择已启用的 CLI 或 Skill；实际调用按会话权限执行。
- 展示工具参数、执行结果与审批请求，以及 Token、费用和上下文用量。
- 支持公开网页搜索与读取，辅助查询资料、总结内容和处理文件。

可以从这些请求开始，根据提示授权路径或先将文件放入中转站：

> “帮我找到授权目录中名称含‘开题’的材料。”
>
> “阅读这份文本，整理出主要内容和待办事项。”
>
> “在中转站中新建‘图片’文件夹，把选中的图片移进去。”

实际效果取决于模型、文件格式和工具权限；支持预览的格式不一定能由模型工具完整解析。

### 2. 文件中转与整理

中转站是用于集中处理文件的临时工作区，可接收来自不同目录的文件和文件夹。

- 拖放、复制、剪切、粘贴，配合目录导航、名称搜索、类型筛选和列表 / 缩略图视图。
- 新建文件夹、重命名、内部移动、ZIP 压缩及批量操作。
- 导出到指定目录或资源管理器，也可还原到原始路径。
- 回收站跨会话恢复，以及当前应用会话内的条件撤销。
- 将剪贴板文字、URL 或图片保存为 `.txt` / `.png`；URL 仅作为文本保存。

**拖入默认是剪切入站：文件会从原位置移入中转站。** 希望保留源文件时，可在资源管理器中复制文件，再到中转站粘贴。重名拖入会在移动前拒绝整批操作，需要用户先处理重名。

### 3. 文件预览

支持图片、文本、Markdown、PDF，以及 DOCX、XLSX、PPTX 的只读预览。Office 以静态文字为主，不保证还原原始排版；PDF 受大小和页数限制。

预览不执行宏、脚本或加载外部资源。不支持、加密、损坏或超限的文件，可交给本机对应应用打开。

### 4. 截图、OCR 与翻译

- 区域 / 可见窗口截图、手动滚动拼接，输出到剪贴板或中转站。
- Windows 本机 OCR 识别截图文字，支持复制与中英翻译。

**0.1.1 主包不包含本地翻译组件和模型，也尚未提供正式组件下载。** 本地翻译需要可信发布方提供 HTTPS 清单并由用户确认安装；MyMemory 需明确同意发送 OCR 文字。独立全局 OCR、翻译快捷键尚未开放，当前从截图确认栏使用。

### 5. 桌面入口与个性化

- 系统托盘与可选宠物悬浮窗，便于快速打开助手或中转站；宠物默认关闭。
- 悬浮中转站支持移动、缩放和侧边停靠，并与宠物联动。
- 跟随系统 / 浅色 / 深色主题，可调整配色、宠物尺寸和全局快捷键。

## 文件访问与执行权限

| 方式 | 访问与操作能力 | 备份与恢复范围 |
|---|---|---|
| 中转站图形界面和受管文件工具 | 在工作区中浏览、整理和处理文件；模型工具不开放永久删除、外部导出和原路径还原，这些操作由用户从界面发起。 | 适用中转站的备份、版本、条件撤销及异常恢复机制，具体取决于操作类型。 |
| 会话外部路径白名单 | 可对授权文件或目录列出、读取、搜索和复制入站；受管文件工具不能直接修改、删除或移动外部源文件。 | 外部源文件保持不变；复制进中转站的文件纳入工作区管理。 |
| 已启用的 CLI / PowerShell | 可调用本机程序完成进一步处理，以当前 Windows 用户权限访问文件和网络。 | 直接修改不进入中转站备份、撤销和恢复流程。 |

“设置 → 会话权限”按会话配置审批模式及文件范围，支持全部、部分或无需批准，以及仅中转站或外部只读白名单。

“设置 → 扩展”管理全局 CLI、PowerShell 和 Skills，新增条目默认关闭。可在“CLI 内置预设”中直接开启 PowerShell 并保存；优先检测 PowerShell 7，回退 Windows PowerShell，已有手动配置会继续使用。Skills 提供操作说明，登记或预览不会自动执行脚本。

CLI 白名单限制可调用的程序入口，**不提供文件或网络隔离**，也不限制该程序启动后的脚本、插件及子进程。使用这类扩展时，应核对命令、参数和目标路径。

## 文件流转与恢复

中转站的典型流程：**文件入站 → 记录原路径并校验备份 → 浏览与整理 → 还原或导出。**

- **正常退出：** 从托盘选择“退出 PowerPet”并完成还原。截图、粘贴内容、复制入站等无原路径项目需明确保存或删除；冲突、失败项和非空回收站会阻止退出。
- **异常恢复：** 崩溃或断电后保留工作区和备份，下次启动核对状态；需人工处理的项目可在“操作与恢复”中查看。
- **撤销限制：** `Ctrl+Z` 仅在当前应用会话有效；自由拖出不保证严格撤销，永久删除无法恢复。

**关闭窗口或隐藏宠物只改变可见性。** 不要手动清理应用数据中的工作区、备份和暂存目录；中转站不能替代长期备份。

## 下载与快速开始

支持 **Windows 10 1903+ / Windows 11 x64**，无需另装 Python、Node.js 或 Bun。本地文件中转与预览可独立使用，AI 需自行配置模型服务。

1. 从 [0.1.1 Release](https://github.com/DYF7812/PowerPet-Releases/releases/tag/v0.1.1) 下载 `PowerPet-0.1.1-Setup.exe` 和 `SHA256SUMS.txt`。
2. 可在下载目录打开 PowerShell，执行下列命令，将结果与校验文件中的对应条目比较：

   ```powershell
   Get-FileHash -LiteralPath .\PowerPet-0.1.1-Setup.exe -Algorithm SHA256
   ```

3. 运行安装程序并启动 PowerPet。当前程序与安装包未进行 Authenticode 签名，Windows 可能显示来源或信誉提示；请核对下载来源和校验值。
4. 阅读首次打开的“设置 → 文件安全”，先用一个测试文件体验入站、预览与原路径还原。
5. 需要 AI 时，在“设置 → Provider 认证”录入 API Key / Token，保存后选择可用模型；根据任务配置会话路径和审批规则。
6. 需要悬浮入口时，在“设置 → 悬浮窗”启用宠物。使用结束后，从系统托盘正常退出。

默认截图快捷键为 `Ctrl+Shift+Q`，显示或收起中转站为 `Ctrl+Shift+Space`；请在快捷键中心确认已启用且注册成功。

安装、升级或卸载前，请先完成文件处理并正常退出应用。卸载会保留应用数据，不能通过卸载代替文件还原。

## 数据与隐私

工作区、备份和会话保存在本机应用数据目录，模型凭据使用 Windows DPAPI 加密保存，OCR 在本机运行。

AI 会将对话及使用的文件内容发送给所选模型服务；联网搜索发送查询词，网页读取访问目标网址且不使用浏览器登录态；MyMemory 经同意后接收 OCR 文字。CLI 的文件和联网行为由所执行程序决定。模型费用、数据保留和隐私规则以服务商说明为准。

## 常见问题

**只能管理桌面上的文件吗？**

可以处理来自文档、下载、项目目录和其他磁盘的用户文件。外部文件可通过会话白名单访问，或放入中转站处理；直接调用 CLI / PowerShell 的权限与恢复边界见上文。

**不使用 AI 可以用吗？**

可以。文件中转、浏览预览、人工整理和本机截图等功能可以独立使用。AI 是可选的实验能力。

**为什么关闭窗口后程序仍在运行？**

关闭窗口会隐藏到托盘，以保留正在中转的文件。要退出，请使用托盘菜单并完成还原或保存流程。

**为什么 AI 读不到某个目录，或者不能修改外部文件？**

先检查该会话的文件范围和授权路径。外部白名单对受管文件工具固定只读；需要受管修改时，可先复制到中转站。CLI 扩展采用另一套执行边界，不能将其直接修改视为有备份保护的操作。

**为什么本地翻译不能下载？**

0.1.1 尚未发布正式的本地翻译组件。没有可信且有效的组件清单时，本地下载不可用；可按需选择 MyMemory 并同意发送 OCR 文字。

**异常退出后如何取回文件？**

重新启动后查看“操作与恢复”，根据提示重试、恢复或处理冲突。保留现有文件副本，不要先删除应用数据目录。

## 技术与发行来源

PowerPet 使用 **Python 3.12、PySide6 / Qt Widgets、SQLite**，通过自包含的 PowerPet Agent Host 接入 Pi SDK 的模型与工具调用能力，采用 PyInstaller `onedir` 打包。

本仓库保存发布页和公开说明，应用源码以 Release 附件提供。0.1.1 采用最小分发，不重复上传便携 ZIP：

| 附件 | 用途 |
|---|---|
| `PowerPet-0.1.1-Setup.exe` | Windows x64 安装包。 |
| `SHA256SUMS.txt` | 安装包与源码附件的 SHA-256 摘要。 |
| `PowerPet-0.1.1-source.zip` | 当前版本必要应用源码和构建文件。 |
| `PowerPet-Pi-0.84.3-source.zip` | 该版本锁定的 Pi 源码。 |

上述文件均可从 [0.1.1 Release](https://github.com/DYF7812/PowerPet-Releases/releases/tag/v0.1.1) 获取。源码附件与本次安装包来自同一份独立构建快照；快照不包含开发仓库历史或内部项目文档。重建方式和第三方依赖来源见随包说明及源码中的构建文件。
