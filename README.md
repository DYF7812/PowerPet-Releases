# PowerPet 0.1.0

PowerPet 将临时文件中转、AI 对话和桌面工具放在一起，适用于 Windows 10 1903+ / Windows 11 x64。

## 下载与开始使用

- 安装包：`PowerPet-0.1.0-Setup.exe`。
- 本次采用最小分发，只提供压缩安装包，不重复上传便携 ZIP。
- 对应源码：`PowerPet-0.1.0-source.zip`；锁定的 Pi 源码另附 `PowerPet-Pi-0.84.3-source.zip`。
- 附件摘要：`SHA256SUMS.txt`。程序及安装包未进行 Authenticode 签名。

**拖入默认是剪切。** 先用测试文件体验入站与原路径还原。关闭窗口只是隐藏；退出应使用托盘菜单，
完成文件还原，或为截图、粘贴文字等无原路径项目选择保存位置。中转站不替代长期备份。
安装、升级、卸载前先正常退出；卸载保留应用数据。

## 本版功能

- 文件和文件夹中转、搜索、整理、导出及原路径还原。
- 图片、文本、Markdown、PDF、Office 静态文字预览。
- 区域截图、Windows OCR、手动滚动截图和截图翻译入口。
- 自带模型凭据的 AI 对话、文件引用、公开网页查询和按会话权限使用工具。
- 明暗主题、全局快捷键、可选桌面宠物与设置页。

## 使用边界和验证情况

AI 会把对话及使用的文件内容发送到你选择的模型服务；联网搜索发送查询词，网页读取访问目标网址。
MyMemory 在线翻译须经同意发送 OCR 文字。本地翻译组件及模型尚未单独发布，主程序不包含这些组件。
已启用的 CLI/PowerShell 使用当前 Windows 用户权限，直接修改不进入中转站备份、撤销和恢复流程。

此版本已经完成打包、安装器编译、附件摘要核对和定向自动化验证。干净 Windows 的安装/升级/卸载、
真实跨卷、Explorer、多显示器/DPI、完整主程序启动及真实模型端到端场景尚未完成全部验收。
不支持屏幕录制、全局取词或自定义宠物外观。AI 属于实验能力。

自有代码采用 MIT；第三方组件保留各自许可证。随包提供本地依赖清单及补充的 Qt/PyWinRT/Bun
法律文本；这些是分发通知和来源证据，不表示已取得第三方商业许可或完整法律审计认证。
依赖来源、重建及修改第三方库的说明见随包文档和所附源码。
