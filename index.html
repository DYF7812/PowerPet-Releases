第一次见面

从一个测试文件开始。

花一分钟，熟悉文件怎么来、怎么回。

  1. 01

    安装 PowerPet

    下载安装包并按向导操作，无需另装 Python。安装或升级前，请先从托盘正常退出旧版本。

  2. 02

    先读“文件安全”

    打开设置中的文件安全页。拖入一个测试文件，再体验原路径还原。

  3. 03

    用托盘菜单正常退出

    关闭窗口只是隐藏。退出时完成还原；截图和粘贴文字等新文件，请选择保存位置或明确删除。

还有几件你可能想知道的事。

需要联网或登录吗？

文件中转与本机预览不需要模型凭据。AI 对话需要你配置服务商的 API Key / Token；费用与服务规则由所选服务商决定。

哪些内容会发送到网上？

AI 会发送对话与使用的文件内容；联网搜索发送查询词，网页读取请求目标网址。MyMemory 在线翻译经你同意后发送 OCR 文字。本地翻译需要另行提供并安装可信组件，当前未提供正式组件下载。启用的 CLI / PowerShell 使用当前 Windows 用户权限，直接改动不进入中转站恢复流程。

卸载前，怎么取回文件？

先停止任务、处理回收站、还原或导出中转站文件，再通过托盘菜单退出。卸载保留应用数据；确认文件完整取回之前，请不要手动删除数据目录。

当前有哪些限制？

0.1.0 为首次公开版本，干净 Windows、跨卷、多显示器及真实模型场景仍待验收。Office 为静态文字预览；尚不支持屏幕录制、全局取词和自定义宠物外观。请以仓库的版本说明和验收记录为准。
