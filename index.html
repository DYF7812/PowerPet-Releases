阅读完整使用介绍 ↗
  1. 01

    下载安装，了解文件安全

    获取安装包并核对 SHA-256，无需另装 Python、Node.js 或 Bun。首次打开后阅读“设置 → 文件安全”。

  2. 02

    体验中转与原路径还原

    用一个测试文件尝试拖入、预览和还原。宠物悬浮窗默认关闭，可在“设置 → 悬浮窗”启用。

  3. 03

    连接模型，配置会话范围

    在“Provider 认证”录入 API Key / Token，选择可用模型，再按任务设置审批与授权路径。

  4. 04

    完成处理，从托盘退出

    还原或导出文件，处理回收站；截图、复制入站等无原路径项目需明确保存或删除。升级、卸载前也请正常退出。

常见问题

反馈问题 ↗
只能管理桌面上的文件吗？

可以处理文档、下载、项目目录和其他磁盘中的用户文件。外部文件可按会话授权读取，或放入中转站整理；启用 CLI / PowerShell 后的直接操作采用上文说明的执行边界。

不使用 AI 可以用吗？

可以。文件中转、浏览预览、人工整理和本机截图可独立使用。AI 是可选的实验能力，需要自行配置模型服务，费用以服务商说明为准。

为什么关闭窗口后程序仍在运行？

关闭窗口会隐藏到托盘。请从托盘选择“退出 PowerPet”并完成文件还原或保存；未处理的冲突、失败项和非空回收站会阻止退出。卸载保留应用数据，不能代替文件还原。

为什么 AI 读不到某个目录，或者不能修改外部文件？

先检查当前会话的文件范围和授权路径。外部白名单对受管工具固定只读，需要受管修改时可先复制到中转站。CLI 的直接修改不受中转站备份和恢复机制保护。

为什么本地翻译不能下载？

0.1.0 未包含本地翻译组件和模型，尚未提供正式组件下载。没有可信的 HTTPS 组件清单时本地下载不可用；可以选择 MyMemory，并明确同意发送 OCR 文字。OCR 与翻译目前从截图确认栏使用，独立全局快捷键尚未开放。

异常退出后如何取回文件？

重新启动后查看“操作与恢复”，按提示重试、恢复或处理冲突。保留现有副本，不要手动删除应用数据目录。通用撤销仅在当前会话有效，自由拖出不保证严格撤销，永久删除无法恢复。

哪些数据保存在本机，哪些会发送到网上？

工作区、备份和会话保存在本机，模型凭据使用 Windows DPAPI 加密，OCR 在本机运行。AI 会将对话及使用的文件内容发送给所选模型服务；搜索发送查询词，网页读取访问目标网址，不使用浏览器登录态。MyMemory 经同意接收 OCR 文字，CLI 的网络行为由所执行程序决定。数据保留规则以服务商说明为准。
